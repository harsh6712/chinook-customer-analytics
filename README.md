# chinook-customer-analytics
SQL + Excel + Power BI customer segmentation analysis on the Chinook database

I built an end-to-end analysis of the Chinook digital music store database to answer a core business question: which customers are most valuable, and which are at risk of churning? The project moved through three tools, each handling a different part of the workflow. In SQL, I wrote 13 queries covering revenue trends, top customers/artists/genres, and RFM (Recency, Monetary) metrics using window functions like RANK and LAG. In Excel, I scored and segmented all 59 customers into 7 tiers (Champions, At Risk, Lost, etc.) using rank-based percentile formulas and XLOOKUP, then built a what-if model estimating the revenue impact of re-engaging At Risk customers. In Power BI, I connected live to the SQLite database and modeled relationships across 8 tables, then built a 2-page interactive dashboard: a business overview (KPIs, revenue trends, top countries/genres) and a customer segmentation page (RFM scatter plot, segment distribution, cross-filtering).

Two honest limitations worth noting: Chinook's invoice frequency is nearly uniform across customers (6-7 orders each), so I excluded Frequency from the RFM model and used a simplified RM (Recency-Monetary) framework instead — a good reminder to validate a framework against the data before applying it. Similarly, the dataset's narrow spend variance meant my what-if revenue model produced a modest dollar impact; in a real-world dataset with more customer diversity, the same segmentation approach would likely surface a much larger opportunity
